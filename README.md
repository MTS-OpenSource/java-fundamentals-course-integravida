# Fundamentos de Java para Principiantes

## Resumen del Curso

Este curso de 1 hora introduce a estudiantes de secundaria a los fundamentos
de la programación con Java, incluyendo conceptos básicos de programación
orientada a objetos (POO). **¡No requiere descargas ni instalaciones!**
Solo necesitas tu navegador web.

**Duración total**: ~62 minutos  
**Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación  
**Requisitos previos**: Ninguno  
**Herramientas necesarias**: Solo tu navegador web (Chrome, Firefox, Safari, Edge)

**📂 Repositorio de Código Fuente**:
[https://github.com/MTS-OpenSource/java-fundamentals-course-integravida](https://github.com/MTS-OpenSource/java-fundamentals-course-integravida)

## Secuencia de Lecciones

### Lección 1: ¿Qué es Java y la Programación? (6 minutos)

- **Descripción**: Descubre qué es la programación, qué es Java y por qué
  es un excelente lenguaje para empezar a programar.
- **Enlace**: [Ver lección](https://www.youtube.com/watch?v=LINK1)
- **Conclusiones clave**:
  - Un programa es una lista de instrucciones para la computadora.
  - Java se usa en aplicaciones, videojuegos y sistemas empresariales.
  - Todo empieza con `System.out.println("Hola, mundo!");`
- **Empieza a practicar**:
  [Abrir editor — Hola Mundo](https://jdoodle.com/execute-java-online/?LINK1)
  👈 **¡Sin registro!**

---

### Lección 2: Variables y Tipos de Datos (8 minutos)

- **Descripción**: Aprende a guardar información en tu programa usando
  variables y conoce los tipos de datos más comunes en Java.
- **Enlace**: [Ver lección](https://www.youtube.com/watch?v=LINK2)
- **Conclusiones clave**:
  - `int edad = 15;` guarda números enteros.
  - `String nombre = "Ana";` guarda texto.
  - `double altura = 1.65;` guarda decimales.
  - `boolean activo = true;` guarda verdadero/falso.
- **Practica aquí**:
  [Abrir editor — Variables](https://jdoodle.com/execute-java-online/?LINK2)
  👈 **¡Sin registro!**

---

### Lección 3: Operadores y Expresiones (6 minutos)

- **Descripción**: Aprende a hacer cálculos y comparaciones dentro de
  tu programa.
- **Enlace**: [Ver lección](https://www.youtube.com/watch?v=LINK3)
- **Conclusiones clave**:
  - Operadores aritméticos: `+`, `-`, `*`, `/`, `%`
  - Operadores de comparación: `==`, `!=`, `>`, `<`
  - Operadores lógicos: `&&`, `||`, `!`
- **Practica aquí**:
  [Abrir editor — Operadores](https://jdoodle.com/execute-java-online/?LINK3)
  👈 **¡Sin registro!**

---

### Lección 4: Estructuras de Control — Decisiones y Bucles (10 minutos)

- **Descripción**: Haz que tu programa tome decisiones con `if-else`
  y repita tareas con bucles `for` y `while`.
- **Enlace**: [Ver lección](https://www.youtube.com/watch?v=LINK4)
- **Conclusiones clave**:
  - `if (edad >= 18) { ... } else { ... }`
  - `for (int i = 0; i < 5; i++) { ... }`
  - `while (condicion) { ... }`
- **Practica aquí**:
  [Abrir editor — Estructuras de Control](https://jdoodle.com/execute-java-online/?LINK4)
  👈 **¡Sin registro!**

---

### Lección 5: Métodos y Entrada/Salida (10 minutos)

- **Descripción**: Aprende a crear bloques de código reutilizables con
  métodos y a leer datos que el usuario escribe.
- **Enlace**: [Ver lección](https://www.youtube.com/watch?v=LINK5)
- **Conclusiones clave**:
  - `public static void saludar(String nombre) { ... }`
  - `Scanner teclado = new Scanner(System.in);`
  - `String entrada = teclado.nextLine();`
- **Practica aquí**:
  [Abrir editor — Métodos y Scanner](https://jdoodle.com/execute-java-online/?LINK5)
  👈 **¡Sin registro!**

---

### Lección 6: Introducción a POO — Clases y Objetos (12 minutos)

- **Descripción**: Descubre el corazón de Java: crea tus propias clases,
  instancia objetos y usa encapsulación con getters y setters.
- **Enlace**: [Ver lección](https://www.youtube.com/watch?v=LINK6)
- **Conclusiones clave**:
  - Una clase es el molde; un objeto es el resultado.
  - Constructor: `public Estudiante(String nombre, int edad) { ... }`
  - Encapsulación: atributos `private`, acceso con `getNombre()` / `setNombre()`
- **Practica aquí**:
  [Abrir editor — Clases y Objetos](https://jdoodle.com/execute-java-online/?LINK6)
  👈 **¡Sin registro!**

---

### Lección 7: Proyecto Final y Buenas Prácticas (10 minutos)

- **Descripción**: Construye una pequeña aplicación POO completa
  (registro de Estudiante) y aprende los errores más comunes que
  debes evitar.
- **Enlace**: [Ver lección](https://www.youtube.com/watch?v=LINK7)
- **Conclusiones clave**:
  - Integra clases, objetos, métodos y Scanner en un solo programa.
  - Usa nombres descriptivos para variables y métodos.
  - Lee los mensajes de error: te dicen exactamente qué corregir.
- **Proyecto final**:
  [Abrir editor — Registro de Estudiante](https://jdoodle.com/execute-java-online/?LINK7)
  👈 **¡Guarda y comparte tu código!**
